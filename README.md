# Telegram Crew — публичная демонстрация

Интерфейс приложения: роли с отдельными ботами сидят в одной группе Telegram и отвечают через локальный Cursor. В комплекте SEO, маркетолог, аналитик и разработчик.

Сайт: https://e-starrrr.github.io/telegram-crew-demo/

Страница показывает интерфейс и хранит правки только в браузере. Ключ Cursor и токены ботов на неё не принимаются и в интернет не отправляются. Рабочая программа запускается локально на Windows.
